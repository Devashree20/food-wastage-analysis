# Food Wastage Analysis Using R

## Project Overview

This project analyzes food wastage data using R programming. The analysis calculates the total and average amount of food wasted and examines food wastage based on different types of food.

## Technologies Used

* R
* RStudio
* CSV Dataset
* Base R Visualization

## Dataset

The dataset contains information about food wastage, including the type of food and the amount of food wasted.

## Analysis Performed

* Displayed the dataset
* Generated summary statistics
* Calculated total food waste
* Calculated average food waste
* Analyzed food waste by food type
* Created graphical visualizations

## Project Structure

```text

├── code/

├── output/

```

## How to Run

1. Download or clone this repository.
2. Open RStudio.
3. Open the R script from the `code` folder.
4. Make sure the dataset is available in the `data` folder.
5. Run the R script to perform the analysis.

## Output

The project generates graphical visualizations showing food wastage based on different food categories.

## Conclusion

The analysis provides a simple understanding of food wastage patterns and demonstrates how R can be used for data analysis and visualization.
